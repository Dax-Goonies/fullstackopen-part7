# 🧩 Full Stack Open — Part 7: Extending the Bloglist, React Router, Redux-style State

Two projects for Part 7 of Full Stack Open, extending earlier material with routing, more advanced state management, and styling.

## 📦 What's here

- **`bloglist/`** — the bloglist app from Parts 4-5, extended with React Router for navigation (users, blogs, individual blog views), centralized state management, and styling.
- **`bloglist-tests/`** — the test suite for the extended bloglist frontend.
- **`routed-anecdotes/`** — the anecdotes app rebuilt with React Router, including routed views, forms, and notifications.
- **`routed-anecdotes-tests/`** — the test suite for the anecdotes app.

## 🛠️ Running

Each project is self-contained:
```bash
cd <project-folder>
npm install
npm start
```

## 🧪 Testing

From within the matching `-tests` folder:
```bash
npm install
npm test
```
